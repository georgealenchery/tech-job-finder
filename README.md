# Tech Job Hunter

A personal job tracking dashboard built with Python and Streamlit.

## Features
- Scrapes live job listings from RemoteOK by keyword
- Stores listings in a local SQLite database
- Track application status per listing (New, Applied, Interview, Rejected, Offer)
- Add personal notes to each listing
- Filter by status or keyword

## Stack
- Python
- Streamlit
- BeautifulSoup4
- SQLite

## Setup
pip install -r requirements.txt
streamlit run app.py
